# Amazon S3

> Crate: [`mws-s3`](../../crates/services/mws-s3) · Tests: [`tests/e2e-rust/tests/e2e/s3.rs`](../../tests/e2e-rust/tests/e2e/s3.rs)

111 of 112 operations are generated from the AWS model (restXml with S3's quirks: no error wrapping, `x-id` routing, `x-amz-meta-*`, raw payloads) and implemented.

✅ supported · 🟡 partial · ❌ not supported

## Requests

| Feature | Status | Details |
| --- | :---: | --- |
| Addressing | ✅ | Path-style and virtual-hosted-style requests; access points by ARN (`{name}-{account}.{endpoint}`) or alias. |
| Authentication | ✅ | SigV4 headers, presigned URLs, `aws-chunked` streaming uploads with chunk and trailer signatures, and browser POST uploads with signed policies. |
| Signature Version 2 | 🟡 | Verified, then refused on bucket requests, as AWS does for buckets created after June 2020. |
| Website endpoints | ✅ | Hosts `*.s3-website*` or `/_aws/s3-website/<bucket>/`, with index and error documents and redirects. |
| Requester Pays | ✅ | Enforced with `x-amz-request-payer`. |

## Buckets and objects

| Feature | Status | Details |
| --- | :---: | --- |
| Buckets | ✅ | Global names, per-account listing, `ExpectedBucketOwner`, AWS's name and Region rules. |
| Objects | ✅ | Metadata, ranges, conditional reads and writes, `CopyObject`, `DeleteObjects`, object attributes and tagging. |
| Checksums | ✅ | CRC32, CRC32C, CRC64NVME, SHA-1 and SHA-256, composite and full-object multipart checksums. |
| Multipart uploads | ✅ | Uploads, part copies, listing and aborts. |
| Versioning | ✅ | Versions, delete markers, `ListObjectVersions`, MFA delete settings. |
| Listing | ✅ | `ListObjects`, `ListObjectsV2` and `ListObjectVersions` with delimiters and pagination. |
| Object Lock | ✅ | Retention modes and legal holds. |
| Directory buckets | ✅ | `name--zone--x-s3` buckets with `s3express:` authorization, `CreateSession` credentials (read-only sessions cannot write), `EXPRESS_ONEZONE` storage, `ListDirectoryBuckets` and `RenameObject`. |
| Archived objects | 🟡 | Restore requests work, but complete immediately. |
| Outposts buckets | ❌ | Requests signed as `s3-outposts` are not routed. |

## Security

| Feature | Status | Details |
| --- | :---: | --- |
| Bucket policies | ✅ | Evaluated by the IAM engine with `aws:ResourceAccount` set to the bucket owner; cross-account access needs both sides; anonymous access through public policies or ACLs. |
| ACLs, ownership controls and Block Public Access | ✅ | Bucket- and account-level Block Public Access (from S3 Control). |
| CORS | ✅ | Configurations and preflight requests. |
| Encryption | ✅ | SSE-S3, SSE-C, and SSE-KMS through KMS with the caller's permissions, plus bucket keys and default encryption. |

## Features that act

| Feature | Status | Details |
| --- | :---: | --- |
| Lifecycle rules | ✅ | Expiration, noncurrent expiration, transitions, multipart aborts and `x-amz-expiration`, on the emulated clock. |
| Replication | ✅ | New versions and delete markers are copied to the destination as the configured role, with replication status on both sides. |
| Event notifications | ✅ | Destinations are checked when configured (the topic, queue or function policy must allow `s3.amazonaws.com`), topics and queues get an `s3:TestEvent`, and object events are delivered to SNS, SQS, Lambda and EventBridge. |
| Server access logs | ✅ | Written to the target bucket as `logging.s3.amazonaws.com` in S3's log format (`SimplePrefix` or `PartitionedPrefix`), one object per request rather than AWS's batches. |
| Inventory reports | 🟡 | Delivered daily or weekly at 00:00 UTC on the emulated clock as gzipped CSV or Parquet with manifests, in AWS's layout; ORC is not written. |
| S3 Select | ✅ | `SelectObjectContent` SQL (projections, `WHERE`, `LIMIT`, `CAST`, `LIKE`, `IN`, `BETWEEN`, `CASE`, string and aggregate functions) over CSV and JSON, GZIP or BZIP2 compressed, with scan ranges, streamed as an event stream. |
| S3 Select over Parquet | ❌ | Not supported. |
| Object Lambda | ✅ | Transformed `GetObject`, `HeadObject` and `ListObjects*` run the Lambda function with a presigned `inputS3Url`; its `WriteGetObjectResponse` becomes the caller's response, with AWS's Lambda error codes. |
